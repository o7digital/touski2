# TOUSKI

Site statique multilingue construit avec Astro.

## Commandes

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Les pages sont générées intégralement en HTML. Les images locales passent par `astro:assets` pour produire des variantes AVIF et WebP responsives. Le sitemap est généré automatiquement pendant la compilation.
